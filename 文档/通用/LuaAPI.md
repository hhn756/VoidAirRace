# LuaAPI

按类别列出插件当前版本的所有 Lua API（对应 `LUA_API_VERSION` = 6）

**本文件与代码保持同步**：API 面每次变更（即版本号递增的场合）必须同步更新此处

错误约定：所有 API 校验失败 / 前置不满足均抛 Lua 错误，文中「静默」为明确标注的例外。查询语义下的「不存在」不算错误：对象、键或路径不存在时返回 `nil` 或空数组

返回约定：表中未注明返回值的函数调用后没有返回值。返回的表都是本次调用新建的快照（数字键数组 1 起始），修改它不会影响引擎或配置。除比赛、竞技场、方块、实体四类句柄表外，引擎不向脚本交出内部对象；句柄表本身也只是函数集合，操作的是它代表的那份引擎状态，失效条件在各节单列

## 语义约定

以下区分贯穿全部 API，各节不再逐条重复：

- **快照 / 句柄**：查询结果与 `config.get` 返回调用瞬间的值快照，之后引擎侧的变化不会反映到已返回的表；句柄（比赛、竞技场、方块对象、实体对象）只固定「代表谁」，每次调用重新读取当前状态，失效即抛错
- **不存在 / 非法**：对象或路径不存在按查询语义返回 `nil` 或空数组；参数类型错误、UUID 非法、越权、句柄失效一律抛错，不用 `nil` 兜底
- **读 / 写**：读取可跨包（`pkgid:...`，须为已声明的直接依赖且已加载）；声明、写入、重载、删除与区域登记只限本包
- **加载期 / 运行期**：包加载脚本执行期间调用失败会使整包加载失败；回调与运行期调用的失败处理见各节（多数记日志并中止该次回调）
- **线程**：所有 API 只在包脚本执行期间调用（加载脚本或引擎回调），全部在主线程；脚本没有异步执行入口

## 全局表总览

插件向每个包的脚本环境（`_G`）装入以下全局表；「不随意操作」的边界即这套表的整体。脚本与这些全局名共享 `_G`：赋值覆盖合法但属于自断手脚，出问题自查；引擎不做写入拦截，包间互不影响

| 全局表        | 职责                                |
|---------------|-------------------------------------|
| `voidairrace` | 插件元数据（无函数）                |
| `server`      | 服务器级操作                        |
| `player`      | 玩家查询                            |
| `arena`       | 竞技场借用                          |
| `event`       | 引擎事件订阅                        |
| `register`    | 元素注册（map / rule / tag 三类别） |
| `resource`    | 包资产访问                          |
| `config`      | 包配置声明与读写                    |

另有四类**句柄表**由函数返回（非全局）：比赛句柄 `match`（回调参数传入）、竞技场句柄（`arena.borrow()` 返回）、方块对象（`arena.get_block()` 返回）与实体对象（`arena.entity_by_uuid` / `arena.find_entity` 返回）

## 值类型

脚本侧的常用值统一为数据形状（命名键表或字符串），没有构造函数，也不带方法；接收点按同一形状解析，校验失败抛 Lua 错误。

| 值         | 形状                             | 说明                                                                    |
|------------|----------------------------------|-------------------------------------------------------------------------|
| 坐标       | `{x = 数字, y = 数字, z = 数字}` | 三个字段必填。浮点坐标用于位置查询与传送                                |
| 方块坐标   | 同上                             | 接收点按向下取整落到方块网格，负数不会朝零截断                          |
| 朝向       | `{yaw = 数字, pitch = 数字}`     | 单位为度；`yaw` 为水平旋转，`pitch` 为俯仰                              |
| 命名空间键 | `"namespace:path"` 字符串        | 用于文本组件的 `font` / `storage` / `show_item.id` / `show_entity.type` |
| 文本组件   | 见「文本组件描述符」节           | 字符串 = 纯文本快捷路径                                                 |
| 方块描述符 | 见「方块描述符」节               | `arena.set` / `arena.fill` 的目标方块                                   |
| 实体键     | `"namespace:path"` 字符串        | 命名空间可省略；用于实体句柄的预期类型与 `arena.spawn` 的 `type`        |
| 物品堆描述符 | `{item = 材质键, count = 数量}` | `count` 省略为 1，不得超过堆叠上限；用于容器物品、装备与掉落物内容     |
| 实体描述符 | 见「实体描述符」节               | `arena.spawn` 的生成参数                                                |

```lua
local p = player.position(uuid)                  -- {x = ..., y = ..., z = ...}
local handle = arena.entity_by_uuid(uuid, "player")
handle.teleport(p, {yaw = 0, pitch = 0})         -- 坐标 + 可选朝向
```

## server

| 函数                         | 说明                                                                                                           |
|------------------------------|----------------------------------------------------------------------------------------------------------------|
| `server.broadcast(message)`  | 向全服在线玩家广播一条文本消息（不限于参赛者）；`message` 为字符串（= 纯文本组件快捷路径）或文本组件描述符表（见「文本组件描述符」节） |
| `server.online_players()`    | 返回当前全部在线玩家的 UUID 字符串数组（1 起始索引）；顺序不保证                                                           |

`broadcast` 只发给调用瞬间在线的玩家，离线玩家收不到，也不补发；`online_players` 是调用瞬间的快照，无人在线时为空数组

## player

玩家以 UUID 字符串表示（值语义）；除 `online` 外，玩家不在线即抛错，UUID 本身非法同样抛错。插件不向脚本交出玩家对象，`position` 返回的是调用瞬间的位置（玩家当前所在世界，不限于比赛世界），需要最新值就再次调用

| 函数                      | 说明                                                                                         |
|---------------------------|----------------------------------------------------------------------------------------------|
| `player.position(uuid)`   | 返回玩家所在世界坐标表 `{x=, y=, z=}`                                                        |
| `player.team_of(uuid)`    | 返回玩家所属队伍的数字 Id（1 起始，与内置队伍顺序一致）；未入队、或队伍无法映射到内置队伍时返回 `nil`                    |
| `player.online(uuid)`     | 返回布尔值：玩家是否在线；UUID 本身非法即抛错（与是否在线无关），离线玩家不抛错              |
| `player.play_state(uuid)` | 返回玩家在 `play` 状态体系下的状态 Id 键名（`"free"` / `"playing"`）；状态未初始化返回 `nil` |

## arena

| 函数             | 说明                                                                                                                   |
|------------------|------------------------------------------------------------------------------------------------------------------------|
| `arena.borrow()` | 借用一个空闲竞技场，返回竞技场句柄表；无空闲即抛错（错误消息列出各占用者）。借入者自动登记为本包，用于审计与包卸载清扫 |

`borrow` 只挑未被任何包或比赛占用的竞技场；借用期间该竞技场不会再次借出，直到 `release` 或引擎清扫。借出不预加载世界，`load` 才把模板复制进竞技场世界

### 竞技场句柄

`arena.borrow()` 返回的表。借用协议由脚本驱动：`load` → 使用（实体入口 `entity_by_uuid` / `find_entity` / `entity_count` / `spawn`，方块入口 `get_block_type` / `get_block` / `set` / `fill`）→ `release`；未先 `load` 就使用其余函数会因世界未就绪而抛错。包卸载时未归还的竞技场由引擎清扫归还（已登记为比赛区域的除外，留给比赛结束流程），归还失败记日志

| 函数                               | 说明                                                                                                              |
|------------------------------------|-------------------------------------------------------------------------------------------------------------------|
| `arena.load(path)`                 | 将包内世界模板目录加载到竞技场；路径规则同 `resource.read_asset`（包根相对，`pkgid:path` 可跨包，须为已声明依赖）。已加载过时重新复制模板，当前世界内的修改会丢弃 |
| `arena.release()`                  | 归还竞技场：世界卸载且不保存修改，场内玩家传回出生点。归还后句柄失效（任何函数再调用即抛错）                      |
| `arena.entity_by_uuid(uuid, type)` | 取得实体句柄（见「实体句柄」节）：`uuid` 为 UUID 字符串，`type` 为预期实体键。取得时不查找实体，之后每次使用再校验；参数非法抛错 |
| `arena.find_entity(uuid, type)`    | 同上，但先做一次存在性检查：实体不存在、类型不符或玩家不在线时返回 `nil`；参数非法仍抛错                          |
| `arena.spawn(pos, 实体描述符)`     | 在竞技场世界生成实体，返回新实体 UUID 字符串；描述符见「实体描述符」节。要求调用方是本竞技场的借入者              |
| `arena.entity_count()`             | 返回竞技场世界当前已加载实体数（数字）：未加载区块中的实体不计入；耗时不承诺常数时间，不宜每 tick 调用            |
| `arena.get_block_type(pos)`        | 返回指定坐标方块的材质键字符串（如 `"minecraft:stone"`，空气为 `"minecraft:air"`）；只查询类型、不需要操作方块时用 |
| `arena.get_block(pos, type)`       | 取得指定方块的方块对象（见「方块对象」节）；`type` 为预期类型（方块材质键），决定对象带哪些类型专属函数；取得时不与方块实际材质比对，材质不符推迟到使用对象时抛错 |
| `arena.set(pos, 方块描述符[, physics])` | 把指定坐标的方块替换为描述符所述方块；`pos` 为坐标表。`physics` 可选，默认 `false`，控制是否触发方块更新；描述符见「方块描述符」节 |
| `arena.fill(pos1, pos2, 方块描述符[, physics])` | 把两个角点围成的长方体（含边界）内每一格替换为描述符所述方块，实体数据逐格写入；角点无顺序要求。格数上限取配置文件 `lua_config.yml` 的 `max_fill_blocks`（默认 32768），超出时在任何写入前抛错；`physics` 同上 |

已登记为比赛区域（`match.widen`）的竞技场手动归还通道关闭（`release` 抛错），归还职责移交比赛结束流程；实体与方块入口（`entity_by_uuid` / `find_entity` / `entity_count` / `spawn` / `get_block_type` / `get_block` / `set` / `fill`）在比赛结束前仍可用

### 方块描述符

`arena.set` / `arena.fill` 接收的命名键表，描述要放置的方块：

| 字段    | 形状   | 说明                                                                                                                                                    |
|---------|--------|---------------------------------------------------------------------------------------------------------------------------------------------------------|
| `type`  | 字符串 | 必填。方块材质键，命名空间可省略，如 `"minecraft:oak_stairs"`、`"stone"`。未知材质抛错                                                                    |
| `state` | 表     | 可选。方块状态属性表 `{属性名 = 值}`，值为字符串、数字或布尔值（数字按整数写法拼入）；省略该字段等同于属性全部取默认值。属性名未知、值不是这三种类型或方块不接受该属性时抛错 |
| `data`  | 表     | 可选。方块实体数据，字段见下表                                                                                                                          |

`data` 的字段全部可选，可同时出现：

| 字段      | 形状                 | 说明                                                                                                                                    |
|-----------|----------------------|-----------------------------------------------------------------------------------------------------------------------------------------|
| `name`    | 文本组件描述符       | 方块实体的自定义名称；目标方块不支持自定义名称时抛错                                                                                    |
| `items`   | 数组                 | 容器物品栏：下标 1 对应槽位 0，每项 `{item = 材质键, count = 数量}`，`count` 省略为 1；数量超过堆叠上限、目标不是容器或项数超过槽位数时抛错 |
| `sign`    | 表 `{front =, back =}` | 告示牌正反面文本：每侧为单个文本组件（占第 1 行）或最多 4 个文本组件组成的数组（按行）；目标不是告示牌时抛错                            |
| `command` | 字符串               | 命令方块指令；目标不是命令方块时抛错                                                                                                    |
| `spawner` | 表 `{entity =, delay =}` | 刷怪笼：`entity` 必填（实体键），`delay` 为延迟刻；目标不是刷怪笼时抛错                                                                |

能力不符在写入方块时抛错；此时方块已按 `type` 与 `state` 放置，实体数据可能只写入了一部分

```lua
arena.set({x = 10, y = 64, z = -3}, {
    type = "minecraft:chest",
    state = {facing = "north", waterlogged = false},
    data = {
        name = "补给箱",
        items = {
            {item = "minecraft:golden_apple", count = 3},
            {item = "minecraft:arrow", count = 16},
        },
    },
})
arena.fill({x = 0, y = 64, z = 0}, {x = 15, y = 64, z = 15}, {type = "minecraft:stone"})
```

### 方块对象

`arena.get_block(pos, type)` 返回的表代表竞技场世界内某一格方块。`type` 为预期类型：脚本给出的方块材质键（`"chest"` 或 `"minecraft:chest"`，大小写不敏感），表示脚本预期该格方块是此材质。预期类型只用于选择方块对象带哪些类型专属函数，不修改方块；取得时不与方块实际材质比对。对象按坐标固定，只记录坐标与预期类型，不持有方块实例，因此不会跟随世界变化指向别的方块；之后每次调用都会重新校验——竞技场已归还、或该格方块不是预期材质时抛错。同一坐标两次取得会得到两个相互独立的对象，对象身份不随方块变化而改变

通用函数（所有方块都有）：

| 函数                       | 说明                                       |
|----------------------------|--------------------------------------------|
| `block.pos()`              | 返回方块坐标表 `{x=, y=, z=}`（整数）      |
| `block.type()`             | 返回材质键字符串（如 `"minecraft:chest"`） |
| `block.hardness()`         | 返回硬度（数字）                           |
| `block.blast_resistance()` | 返回爆炸抗性（数字）                       |
| `block.slipperiness()`     | 返回摩擦系数（数字）                       |
| `block.is_solid()`         | 是否固体                                   |
| `block.is_liquid()`        | 是否液体                                   |
| `block.is_passable()`      | 是否可穿过                                 |
| `block.is_flammable()`     | 是否可燃                                   |
| `block.has_gravity()`      | 是否受重力影响                             |
| `block.is_occluding()`     | 是否遮挡光线                               |

方块属于容器（箱子、木桶、熔炉等）时，表中另有：

| 函数                        | 说明                                                                                                     |
|-----------------------------|----------------------------------------------------------------------------------------------------------|
| `block.size()`              | 返回容器物品栏格数                                                                                       |
| `block.get(slot)`           | 返回指定槽位的物品描述符（`{item =, count =}`），空槽返回 `nil`                                          |
| `block.items()`             | 返回非空槽位数组，每项为 `{slot = 槽位, item = 材质键, count = 数量}`，按槽位升序                        |
| `block.set(slot, item)`     | 把指定槽位设为物品描述符所述物品                                                                         |
| `block.add(item)`           | 把物品放入第一个能容纳的位置，返回未能放入的数量（0 表示全部放入）                                       |
| `block.remove(slot)`        | 清空指定槽位                                                                                             |
| `block.clear()`             | 清空整个物品栏                                                                                           |
| `block.loot_table()`        | 返回容器绑定的战利品表 Id 字符串；未绑定或该容器不支持战利品表时返回 `nil`                               |
| `block.set_loot_table(id)`  | 给容器绑定战利品表；`id` 为 `ns:path`（省略命名空间按 `minecraft`），表须已存在                          |
| `block.clear_loot_table()`  | 解除容器绑定的战利品表                                                                                   |

- 槽位按 Lua 习惯 1 起始（第 1 格对应物品栏下标 0），越界或非整数抛错
- 物品描述符与方块描述符 `data.items` 中的项同形：`{item = 材质键, count = 数量}`，`count` 省略为 1
- 写函数（`set` / `add` / `remove` / `clear` / `set_loot_table` / `clear_loot_table`）要求调用方是本竞技场的借入者；读函数不需要
- 战利品表在容器首次被打开时生成；绑定新表不会清空已有物品，重置补给箱应先 `clear()`。插件自带数据包中的表可以直接引用

```lua
local chest = arena.get_block({x = 10, y = 64, z = -3}, "chest")
chest.clear()
chest.set_loot_table("void_air_race:maps/grass_land/supply")
server.broadcast("箱子有 " .. chest.size() .. " 格，硬度 " .. chest.hardness())
```

专属函数按预期类型对应的方块大类提供：所有容器材质共用同一组容器函数，其余方块只有通用函数

### 实体句柄

`arena.entity_by_uuid(uuid, type)` / `arena.find_entity(uuid, type)` 返回的表代表竞技场世界内的某个实体。`type` 为预期实体键（`"zombie"` 或 `"minecraft:zombie"`），只用于选择句柄带哪些类型专属函数、并作为句柄的类型断言；取得时不与实体实际类型比对。句柄只记录竞技场、UUID 与预期类型，不保存实体实例或坐标；之后每次调用都重新按 UUID 查找——竞技场已归还、实体不存在（含所在区块未加载）或实体类型与预期不符时抛错。同一 UUID 两次取得会得到两个相互独立的句柄

句柄可用的函数组由预期类型决定，与实体当前状态无关：`minecraft:player` 得到玩家句柄；`minecraft:armor_stand` 得到盔甲架句柄；其余按服务端对应的实体类落到画、掉落物、敌对生物、动物、生物、活体，都不匹配时为通用句柄

非玩家实体只在已加载区块里可查：区块未加载时 `exists()` 返回 `false`、读取抛错、`find_entity` 返回 `nil`，这不等同于实体被删除，区块重新加载后同一 UUID 的句柄恢复可用。玩家句柄按在线状态判定，与所在世界、区块无关；玩家重生、跨维度后 UUID 不变，句柄继续可用。实体离开竞技场世界后原句柄失效，需要在目标竞技场的句柄上重新获取

通用函数（所有非玩家实体都有）：

| 函数                                       | 说明                                                                                     |
|--------------------------------------------|------------------------------------------------------------------------------------------|
| `entity.uuid()`                            | 返回 UUID 字符串；不访问世界，实体消失也返回                                             |
| `entity.type()`                            | 返回预期实体键字符串；不访问世界，实体消失也返回                                         |
| `entity.exists()`                          | 当前能否按 UUID 找到、类型是否匹配且仍存活；不抛错（借据失效除外）                        |
| `entity.pos()`                             | 返回当前浮点坐标表 `{x=, y=, z=}`                                                        |
| `entity.rotation()`                        | 返回当前朝向表 `{yaw=, pitch=}`                                                          |
| `entity.teleport(pos[, rot])`              | 在本世界内传送；`rot` 省略时保留当前朝向                                                 |
| `entity.teleport_to(arena, pos[, rot])`    | 传送到指定竞技场世界；目标区块未加载时先加载，传送后不卸载                               |
| `entity.remove()`                          | 直接从世界移除，无掉落、无死亡事件；与 `kill()` 分开                                    |

活体句柄另有：

| 函数                                     | 说明                                                                                     |
|------------------------------------------|------------------------------------------------------------------------------------------|
| `entity.health()`                        | 返回当前生命值                                                                           |
| `entity.set_health(n)`                   | 设置当前生命值；超过上限按上限处理，负数或非有限数字抛错                                 |
| `entity.kill()`                          | 走正常死亡流程（掉落、死亡事件）；返回调用后是否已进入死亡状态，无敌或伤害被取消时为 `false` |
| `entity.invisible()` / `entity.set_invisible(b)` | 是否隐身                                                                         |

生物句柄另有：

| 函数                                     | 说明                                                                                     |
|------------------------------------------|------------------------------------------------------------------------------------------|
| `entity.ai()` / `entity.set_ai(b)`        | 是否启用 AI                                                                              |
| `entity.baby()` / `entity.set_baby(b)`    | 是否幼年；当前实体不支持成长时抛错                                                       |

盔甲架句柄另有 `entity.arms()` / `entity.set_arms(b)`、`entity.small()` / `entity.set_small(b)`、`entity.marker()` / `entity.set_marker(b)`、`entity.base_plate()` / `entity.set_base_plate(b)`，均为布尔读写。掉落物句柄另有：

| 函数                                     | 说明                                                                                     |
|------------------------------------------|------------------------------------------------------------------------------------------|
| `entity.item()`                          | 返回掉落物内容，形状为物品堆描述符                                                       |
| `entity.set_item(物品堆描述符)`          | 替换掉落物内容                                                                           |

画句柄另有：

| 函数                | 说明                                                         |
|---------------------|--------------------------------------------------------------|
| `entity.art()`      | 返回画作键字符串，如 `"minecraft:kebab"`                    |
| `entity.facing()`   | 返回附着方向：`"north"` / `"south"` / `"east"` / `"west"`    |

玩家句柄不与非玩家句柄共根，函数表单独一组；句柄上的竞技场只用于借据生命周期与传送权限，玩家不必站在该竞技场世界内。玩家句柄没有 `remove` / `kill`：

| 函数                                      | 说明                                                                                    |
|-------------------------------------------|-----------------------------------------------------------------------------------------|
| `handle.uuid()`                           | 返回 UUID 字符串                                                                        |
| `handle.type()`                           | 固定返回 `"minecraft:player"`                                                           |
| `handle.exists()`                         | 玩家是否在线；离线不抛错                                                                 |
| `handle.pos()`                            | 返回玩家当前位置浮点坐标表；离线即抛错                                                   |
| `handle.rotation()`                       | 返回玩家当前朝向表；离线即抛错                                                           |
| `handle.teleport(pos[, rot])`             | 在玩家当前世界内传送                                                                    |

```lua
    zombie.set_health(10)
    zombie.teleport({x = 5, y = 65, z = 5}, {yaw = 180, pitch = 0})
end
```

### 实体描述符

`arena.spawn` 接收的命名键表，描述要生成的实体：

| 字段    | 形状               | 说明                                                                                                  |
|---------|--------------------|-------------------------------------------------------------------------------------------------------|
| `type`  | 实体键             | 必填。命名空间可省略；必须是可生成的非玩家实体，`"player"` 与不可生成类型抛错                          |
| `rot`   | 朝向表             | 可选。生成时朝向；省略时水平与俯仰均为 0                                                              |
| `name`  | 文本组件描述符     | 可选。自定义名称                                                                                      |
| `data`  | 表                 | 可选。类型专属数据，字段见下表                                                                        |

`data` 的字段全部可选：

| 字段                                                | 适用类型   | 说明                                                                                     |
|-----------------------------------------------------|------------|------------------------------------------------------------------------------------------|
| `ai`                                                | 生物       | 是否启用 AI                                                                              |
| `baby`                                              | 可成长实体 | 是否幼年                                                                                 |
| `silent` / `glowing` / `invulnerable` / `gravity`    | 全部       | 对应实体属性                                                                             |
| `persistent`                                        | 全部       | 是否随区块保存；省略为 `true`                                                            |
| `name_visible`                                      | 全部       | 自定义名称是否可见；省略时写了 `name` 即为 `true`，否则保持服务端默认                    |
| `invisible`                                         | 活体       | 是否隐身                                                                                 |
| `equipment`                                         | 活体       | 装备表：`mainhand` / `offhand` / `head` / `chest` / `legs` / `feet`，每项为物品堆描述符   |
| `item`                                              | 掉落物     | 掉落物内容；掉落物必填，其余类型不可出现                                                 |
| `painting`                                          | 画         | 表 `{art = 画作键, facing = 方向}`，两字段均可选；`art` 省略时由服务端选择放得下的画作    |
| `armor_stand`                                       | 盔甲架     | 表 `{arms =, small =, marker =, base_plate =}`，均为布尔                                 |

能力不符在接触世界前抛错：字段只允许写在具备对应能力的类型上，比如给僵尸写 `painting`、给掉落物不写 `item`、给不支持的实体写 `baby`

生成规则：

- `pos` 为浮点坐标；坐标必须在该竞技场世界内：X/Z 在世界边界内，Y 在世界高度范围内
- 每个竞技场世界的已加载实体数上限为 8192，达到上限时抛错、不生成
- 目标区块未加载时先加载，不需要提前加载；区块原本未加载时，生成完成后立即卸载并保存，这种实体在区块再次加载前无法被句柄找到
- 生成被服务端拒绝（生成事件取消等）时抛错；画作放不下时移除已生成的实体再抛错
- 生成成功返回新实体 UUID 字符串

```lua
local uuid = arena.spawn({x = 10.5, y = 65, z = -3.5}, {
    type = "zombie",
    rot = {yaw = 90, pitch = 0},
    name = "守卫",
    data = {
        ai = false,
        silent = true,
        equipment = {mainhand = {item = "minecraft:iron_sword", count = 1}},
    },
})
```

### 修改权限边界

用户包只能修改自己借到的竞技场，以及自己有修改权的比赛——自己注册地图的比赛，或本场已启用自己 Lua 规则的比赛。归属裁定在引擎侧统一进行，不暴露给脚本，越界即抛错：

- 竞技场资源：`arena.load` / `arena.set` / `arena.fill` / `arena.spawn`、容器句柄的全部写函数（`set` / `add` / `remove` / `clear` / `set_loot_table` / `clear_loot_table`）与非玩家实体句柄的全部写函数（`remove` / `kill` / `teleport` / `teleport_to` / 各 `set_*`）要求借用者是当前包；`match.widen` 只能登记本包借到的竞技场
- 非玩家实体跨竞技场传送：`entity.teleport_to` 要求调用方同时是来源竞技场与目标竞技场的当前借入者
- 玩家：玩家句柄的 `teleport` / `teleport_to` 还要求目标玩家属于上述比赛（含已淘汰者）；玩家当前所在世界若是竞技场世界，还要求该竞技场由当前包借入。地图开局回调 `on_start` 执行时比赛处于启动阶段，同样放行；规则被本场启用即授予其来源包同等修改权
- 没有进行中的比赛时，玩家句柄的 `teleport` / `teleport_to` 一律抛错——即使竞技场是自己借的，也不能借此挪动无关玩家
- 事件回调只递值载荷（UUID、状态名等）与末位的比赛句柄，不暴露可修改的实体对象或事件对象；读取类 API 不受此限。比赛句柄按归属授予：本包不是本场地图注册方、也没有在本场启用 Lua 规则时只读

## event

| 函数                       | 说明                                                                                                                                                                              |
|----------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `event.on(name, callback)` | 订阅引擎事件；`name` 为下方「事件」表里的名称（未知即抛错）。同一事件可登记多个监听器（含同一函数重复登记），按登记顺序调用；回调在主线程执行，事件字段作为位置参数传入，回调返回值被忽略，每次调用单独计算指令预算（执行预算单位，与游戏 tick 无关，耗尽即中止该次回调）。无返回值 |
| `event.off(callback)`      | 按监听器函数退订：移除该函数在所有事件类型上的全部登记（函数须为登记时的同一个函数值）；未登记时静默无操作                                                                        |

订阅只在当前这次包加载内有效：包卸载时全部订阅随桥接一起清除，不做持久化。

### 事件列表

| 事件名                 | 回调签名                                            | 触发时机                                                                   |
|------------------------|-----------------------------------------------------|----------------------------------------------------------------------------|
| `"player_join_match"`  | `function(uuid, match)`                             | 玩家加入比赛（开局不会为初始参赛者补发）                                   |
| `"player_leave_match"` | `function(uuid, match)`                             | 玩家退出比赛（淘汰/离场）                                                  |
| `"match_start"`        | `function(match)`                                   | 比赛开始                                                                   |
| `"match_time_expired"` | `function(match)`                                   | 比赛剩余时间归零时触发一次（含脚本把剩余时间直接设为 0）；倒计时递减不触发 |
| `"match_over"`         | `function(match)`                                   | 比赛结束；句柄只放行查询                                                   |
| `"player_join"`        | `function(uuid, match_or_nil)`                      | 玩家加入服务器                                                             |
| `"player_quit"`        | `function(uuid, match_or_nil)`                      | 玩家离开服务器                                                             |
| `"player_death"`       | `function(uuid, killer_uuid_or_nil, match_or_nil)`  | 玩家死亡；击杀者是玩家时给出其 UUID，否则 `nil`                            |
| `"player_respawn"`     | `function(uuid, match_or_nil)`                      | 玩家重生                                                                   |
| `"player_move"`        | `function(uuid, pos, match_or_nil)`                 | 玩家所在方块变化；同方块内走动与转头不触发                                 |
| `"entity_spawn"`       | `function(uuid, type, match_or_nil)`                | 非玩家实体在竞技场世界生成，含脚本生成与自然生成                           |
| `"entity_death"`       | `function(uuid, type, killer_uuid_or_nil, match_or_nil)` | 非玩家活体在竞技场世界死亡；击杀者为实体时给出其 UUID，否则 `nil`     |
| `"entity_remove"`      | `function(uuid, type, cause, match_or_nil)`         | 非玩家实体从竞技场世界移除；死亡与区块卸载不派发                           |

回调抛错时记日志并广播原因，不自动终止比赛。参数只含值（UUID 字符串、状态名、坐标表）与末位的比赛句柄，不暴露事件对象，也不支持取消与改写

比赛句柄参数：比赛域事件给的是事件所属比赛；玩家与实体事件不属于某一场比赛，给当前比赛（没有进行中的比赛时为 `nil`）。句柄按归属授予——本包是本场地图的注册方，或在本场启用了自己的 Lua 规则时得到完整句柄，否则只读，操作类函数（`join` / `leave` / `stop` / `set_remaining` / `set_time_flow` / `widen` / `enable_rule`）抛错。`match_over` 的句柄与地图 `on_over` 一样只放行查询

实体事件只覆盖竞技场世界内的非玩家实体，玩家事件沿用 `player_*`。`entity_remove` 的 `cause` 为小写下划线字符串，取值：`despawn`、`drop`、`enter_block`、`explode`、`hit`、`merge`、`out_of_world`、`pickup`、`plugin`、`transformation`、`discard`。死亡不派发 `entity_remove`（由 `entity_death` 表示），区块卸载也不派发——实体仍在存档中。事件不携带竞技场标识，订阅者可能收到其他竞技场世界的事件；要判断是否为本场实体，用自己的竞技场句柄调 `find_entity`，返回 `nil` 即不属于该竞技场

`player_move` 是唯一按位置触发的事件：只在跨方块时派发，同一玩家两次派发至少间隔 50ms（约每秒 20 次上限），坐标表为派发时玩家所在位置、不保证覆盖途经的每个方块；无人订阅时桥接在源头直接返回。需要更细的位置可在地图 `on_tick` 或规则 `tick` 回调里经 `player.position` 轮询

## register

类别注册函数，描述符（表）为唯一参数。注册调用即时写入注册表：加载期调用失败导致整包加载失败；运行期调用同样生效，失败按回调异常处理。同一类别内 `id` 重复注册抛错。`id` 只写键名（小写字母/数字/下划线/连字符），插件自动加包前缀。全部字段：

| 函数                        | 必填字段                    | 可选字段                                                                                   | 可选回调                                               |
|-----------------------------|-----------------------------|--------------------------------------------------------------------------------------------|--------------------------------------------------------|
| `register.map(descriptor)`  | `id`、`max_teams`（正整数） | `names`、`description`、`authors`、`links`、`display_version`、`version`、`tags`            | `on_start(match)`、`on_tick(match)`、`on_over(match)`  |
| `register.rule(descriptor)` | `id`                        | `names`、`description`、`authors`、`links`、`display_version`、`version`、`tags`            | `on_enable(match)`、`on_disable(match)`、`tick(match)` |
| `register.tag(descriptor)`  | `id`                        | `names`、`description`、`authors`、`links`、`display_version`、`version`（无 `tags`，写了不生效） | —                                                      |

- 展示字段 `names` / `description` / `authors` / `links` 为数组，每项为字符串（= 纯文本组件快捷路径）或文本组件描述符表；`display_version` / `version` 为单值（前者组件、后者正整数）。`links` 与其余展示字段同构，只用于展示，插件不解析其中的链接目标
- `tags`：字符串数组；裸键自动加包前缀，跨命名空间写全名 `ns:key`；引用必须是已注册标签（自身包、插件内置或已声明依赖），地图与规则描述符中的引用须 `register.tag` 先行
- 回调参数均为比赛句柄（见「比赛句柄 match」节），在主线程执行，返回值按下述协议处理：
  - `on_start(match)`：比赛启动时执行（组件安装完成后、状态仍为启动阶段）。返回值被忽略；抛错即比赛启动失败
  - `on_tick(match)`：地图启用期间每个游戏 tick 调用一次（`on_start` 成功后到 `on_over` 前，主线程）。返回值被忽略；抛错只记日志，不影响比赛
  - `tick(match)`：规则启用期间每个游戏 tick 调用一次。返回值被忽略；抛错只记日志，不影响比赛
  - `on_enable(match)`：规则启用时执行。须返回 `true`（或 `true, 其他值`）才算启用成功；返回 `false, err` 或其他任何值都按启用失败处理，`match.enable_rule` 随之抛错，`err` 为字符串时作为失败原因
  - `on_disable(match)` / `on_over(match)`：规则停用 / 比赛收尾时执行。返回值被忽略；抛错只记日志，不阻断流程

## 文本组件描述符

接收点（`server.broadcast`、`register.*` 展示字段）接受字符串（= 纯文本组件快捷路径）或描述符表——组件在 Lua 侧是数据形状，转换单向（描述符 → 组件）。描述符为 snake_case，样式字段内联在组件表上，对应 Minecraft 文本组件定义（Paper 1.21.11 / Adventure 4.26.1 支持范围）：

| 字段                                                              | 说明                                                                                                                                                                                                                        |
|-------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `type`                                                            | 组件类型：`"text"`（缺省）/ `"translatable"` / `"keybind"` / `"score"` / `"selector"` / `"nbt"`                                                                                                                             |
| `text`                                                            | text 类型的内容（可省，缺省空文本）                                                                                                                                                                                         |
| `translate` / `fallback` / `args`                                 | translatable：键必填；fallback 可选；args 为数组，每项可嵌套任意描述符                                                                                                                                                      |
| `keybind`                                                         | keybind 类型的按键绑定标识（如 `"key.jump"`），必填                                                                                                                                                                         |
| `objective` / `name`                                              | score：objective 必填；name 缺省空串（= 读者自身）                                                                                                                                                                          |
| `selector` / `separator`                                          | selector：选择器必填（如 `"@p"`）；separator 可选（字符串）                                                                                                                                                                 |
| `block` / `entity` / `storage` / `nbt` / `interpret` / `separator`              | type 为 `nbt` 时：来源三选一（block 坐标串支持 `~`；entity 为选择器或 UUID；storage 为资源路径）；`nbt` 为 NBT 路径必填；`interpret` 存在即为 true；`separator` 可选（字符串）                                                         |
| `color`                                                           | 颜色名（`"red"` 等 16 色）或 `"#RRGGBB"`                                                                                                                                                                                    |
| `bold` / `italic` / `underlined` / `strikethrough` / `obfuscated` | 三态装饰：true 显式开 / false 显式关 / 省略继承                                                                                                                                                                             |
| `font`                                                            | 字体 Key 串                                                                                                                                                                                                                 |
| `insertion`                                                       | 按住 Shift 点击时插入聊天框的文本                                                                                                                                                                                           |
| `click_event`                                                     | 表：`action` + `value`。action 闭集：`open_url`（http/https）/ `run_command` / `suggest_command` / `change_page`（正整数）/ `copy_to_clipboard`。`open_file` 不开放：Minecraft 客户端协议不允许该动作，发包时会被服务端拒绝 |
| `hover_event`                                                     | 表：`action` 与其余字段同级（不在 `value` 子表内）。`show_text`（value=字符串/描述符）/ `show_item`（id 必填，count 缺省 1，正整数）/ `show_entity`（type + id(UUID) 必填 + name 组件可选）                                        |
| `extra`                                                           | 子组件描述符数组，任意嵌套（深度上限 32）                                                                                                                                                                                   |

校验失败抛 Lua 错误，错误消息携带嵌套路径。

## resource

| 函数                          | 说明                                                                                         |
|-------------------------------|----------------------------------------------------------------------------------------------|
| `resource.read_asset(path)`   | 读取资产文件，返回二进制安全字符串；按字节读取、不解码文本，单文件上限 16 MiB（超限抛错）；目标不是文件抛错。路径规则同 `arena.load` |
| `resource.list_assets(path?)` | 列出资产目录的直属条目，返回按名称排序的字符串数组，目录条目名以 `/` 结尾，不递归；`path` 省略或空串时列出本包根，空目录返回空数组，目标不是目录抛错。路径规则同 `read_asset`（`pkgid:path` 可跨包，须为已声明依赖） |

资产只读，没有写入接口；跨包访问同样只读。需要脚本持久写入的数据用 `config`，不要试图修改资产文件。

## config

包配置：由插件保存在独立于包资产的位置，储存为 yml。包卸载不清除配置，只有 `config.delete` 才移除

配置 id 为文件 id（本包）或 `pkgid:fileId`（跨包读取，目标包须为已声明的直接依赖且已加载）。文件 id 只允许小写字母、数字、下划线、连字符，以 `/` 分段，不含扩展名（由插件统一补 `.yml`）

| 函数                        | 范围   | 说明                                                                                                                                         |
|-----------------------------|--------|----------------------------------------------------------------------------------------------------------------------------------------------|
| `config.declare(id, schema)` | 本包   | 声明配置的键与默认值；重复声明以最后一次为准。文件不存在时按 schema 生成，已存在时补入缺失键。schema 叶子只允许 boolean / number / string / 表 |
| `config.exists(id)`          | 可跨包 | 配置文件是否存在于磁盘（布尔值）                                                                                                             |
| `config.get(id, path?)`      | 可跨包 | 返回配置快照：省略 `path` 返回整份配置；路径不存在、或路径中间段不是映射时返回 `nil`；文件不存在抛错                                          |
| `config.set(id, path, value)`| 本包   | 写入点分路径并立即保存；路径中间段必须是映射或不存在；`value` 只允许 boolean / number / string / 表                                                            |
| `config.reload(id)`          | 本包   | 驱逐内存缓存并从磁盘重新加载                                                                                                                 |
| `config.delete(id)`          | 本包   | 删除配置文件、内存缓存与键声明；文件不存在时静默                                                                                             |

「本包」函数收到其他包的 id 即抛错；「可跨包」函数要求目标包是已声明的直接依赖且已加载，否则抛错

### 读取

- `get` 每次返回新建快照，修改返回的表不会写回配置；整份配置包含文件里的全部键，包括未在 schema 声明的键
- 省略 `path` 或传空串返回整份配置；`path` 为点分键路径
- 路径不存在返回 `nil`；路径中间段不是映射时同样返回 `nil`，不抛错——例如 `a` 存的是数字、字符串或列表，却查询 `a.b`。这与直接对 Lua 表做链式索引不同（后者会报错），配置访问把「中间段缺失」与「中间段不可向下」都当作路径不存在
- 值转换（yml → Lua）：映射 / 配置节 → 字符串键表；列表 → 1 起始数组表；boolean、整数、浮点、字符串保持原类型；其余标量转字符串；空映射 → 空表

### 键声明

schema 的形状约定：

- 键名下挂标量即一个配置键；下挂映射（字符串键表）递归展开为点分路径
- 键恰为 `1..n` 的序列整体作为一个键，值为列表；空表整体作为一个键，值为空映射
- 键名不能包含 `.`；schema 嵌套深度上限 32、节点数上限 4096，值表嵌套深度上限 32

`declare` 的行为：

- 立即物化配置文件：文件不存在时按 schema 生成；已存在时只补入缺失键，不覆盖已写入的值
- 重复声明同一文件以最后一次为准，已有配置值保留
- 键声明常驻，不随包卸载清除，只有 `delete` 或再次 `declare` 才改变

### 写入

- `set` 的路径为点分键路径，空路径或空键段抛错
- 路径中间段必须是映射或尚不存在：中间段是标量或列表时抛错（避免静默覆盖结构）；缺失的中间段按映射创建
- 可写未声明的键；schema 只用于生成默认值与约束声明时的默认值类型，不限制可写键集合
- 值转换（Lua → yml）：boolean / number / string 原样；键恰为 `1..n` 的表 → 列表；其余表 → 字符串键映射；空表 → 空映射。`nil`、非字符串键、循环引用、超深或超节点均抛错
- 写入立即原子保存到磁盘

### 缓存与磁盘

- `exists` 直接检查磁盘文件；`get` / `set` / `reload` 使用内存缓存
- 文件在插件之外被改动后，内存中的旧值不会自动更新；先 `reload` 再读取或写入，否则 `get` 读到旧值，`set` 会以旧内容为底整份保存，覆盖外部修改
- `reload` 驱逐缓存并从磁盘重读，文件不存在抛错
- `delete` 删除文件、缓存与键声明，文件本就不存在时静默；删除后 `get` 抛「文件不存在」，`exists` 返回 `false`

## 比赛句柄 match

地图与规则回调、事件回调收到的 `match` 参数——薄门面，每次回调现造，无需脚本管理生命周期。前缀「进行中」的函数要求比赛处于启动或进行中（地图 `on_start` 在启动阶段执行）；「查询」类函数在地图 `on_over` 收尾回调中也可用，规则 `on_disable`（比赛已进入结束流程）及此后的其余场合一律抛错（`match.state()` 除外）

事件回调可能收到只读句柄：本包不是本场地图注册方、也没有在本场启用自己的 Lua 规则时，操作类函数一律抛错，查询不受影响

句柄与比赛同生共死：`stop()` 调用后或比赛进入结束流程后，普通句柄的函数一律抛错，仅 `state()` 可用；只有地图 `on_over` 与 `match_over` 事件收到的收尾句柄放行查询函数（见上一段）。数组返回值都是调用瞬间的快照；`contestants` 固定为初始参赛者，之后经 `join` 加入的玩家不在其中

| 函数                        | 前置   | 说明                                                                                                                                                               |
|-----------------------------|--------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `match.state()`             | 无     | 返回比赛状态名字符串（如 `"IN_PROGRESS"`），与比赛状态枚举一一对应；唯一在任何阶段都可调用的函数                                                                   |
| `match.contestants()`       | 查询   | 返回初始参赛者的 UUID 字符串数组（1 起始索引）——比赛开始时在场的玩家                                                                                               |
| `match.survivors()`         | 查询   | 返回当前仍存活的参赛者 UUID 字符串数组                                                                                                                             |
| `match.eliminated()`        | 查询   | 返回已淘汰的参赛者 UUID 字符串数组                                                                                                                                 |
| `match.surviving_teams()`   | 查询   | 返回仍有存活参赛者的队伍数字 Id 数组（1 起始）                                                                                                                     |
| `match.player_ranking()`    | 查询   | 返回玩家排行 UUID 字符串数组（1 起始索引，第 1 项为第一名）：先退赛者在前，未退赛者按加入顺序排末尾                                                                |
| `match.team_ranking()`      | 查询   | 返回队伍排行数字 Id 数组（1 起始索引，第 1 项为第一名）：按队伍首个成员退赛的先后排列，仍有存活成员但无人退赛的队伍排在末尾；无法映射到内置队伍的条目被跳过           |
| `match.join(uuid)`          | 进行中 | 使指定玩家加入本场比赛：已在本场且仍存活时幂等无操作；已淘汰者不能重新加入；离线者、非空闲状态者抛错                                                               |
| `match.leave(uuid)`         | 进行中 | 使指定玩家退出比赛（淘汰）；玩家不在参赛集合中时静默无操作                                                                                                         |
| `match.stop()`              | 进行中 | 结束本场比赛；仅当句柄属于协调器管理的当前比赛，否则抛错。收尾流程（组件卸载、`on_over`、`match_over` 事件）由引擎统一执行，调用后本句柄除 `state()` 外失效             |
| `match.remaining()`         | 进行中 | 返回剩余比赛时长（tick 数，非负整数）                                                                                                                              |
| `match.set_remaining(n)`    | 进行中 | 设置剩余比赛时长；`n` 为 tick 数，须为非负整数。设为 0 会按剩余时间归零立即触发一次 `match_time_expired`                                                        |
| `match.time_flow()`         | 进行中 | 返回比赛时间是否随 tick 减少（布尔值）                                                                                                                             |
| `match.set_time_flow(flag)` | 进行中 | 设置比赛时间是否随 tick 减少：`flag` 须为布尔值，`true` 减少、`false` 暂停                                                                                      |
| `match.widen(arena, tag)`   | 进行中 | 把竞技场登记为本场比赛的区域；`arena` 须为本包借到的竞技场句柄表，`tag` 为区域标签名（当前可用 `"main"`）。登记后竞技场归还职责移交比赛结束流程，`release` 被拒绝 |
| `match.enable_rule(spec)`   | 进行中 | 在比赛中启用指定规则；`spec` 为规则 Id 字符串（裸键 = 自身包命名空间，或 `ns:key` 全名），命名空间须为自身包 / 插件内置 / 已声明依赖；规则须已注册，启用失败（含 `on_enable` 未返回 `true`）即抛错 |
