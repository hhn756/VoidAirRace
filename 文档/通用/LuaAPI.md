# LuaAPI

按类别列出插件当前版本的所有 Lua API（对应 `LUA_API_VERSION` = 5）

**本文件与代码保持同步**：API 面每次变更（即版本号递增的场合）必须同步更新此处

错误约定：所有 API 校验失败 / 前置不满足均抛 Lua 错误，文中「静默」为明确标注的例外

## 全局表总览

插件向每个包的脚本环境（`_G`）装入以下全局表；「不随意操作」的边界即这套表的整体。脚本与这些全局名共享 `_G`：赋值覆盖合法但属于自断手脚，出问题自查；引擎不做写入拦截，包间互不影响

| 全局表        | 职责                                |
|---------------|-------------------------------------|
| `voidairrace` | 插件元数据（无函数）                |
| `server`      | 服务器级操作                        |
| `player`      | 玩家查询                            |
| `arena`       | 竞技场借用                          |
| `event`       | 引擎事件订阅                        |
| `register`    | 元素注册（map / rule / tag 三类别） |
| `resource`    | 包资产访问                          |

另有两类**句柄表**由函数返回（非全局）：比赛句柄 `match`（回调参数传入）与竞技场句柄（`arena.borrow()` 返回）

## 值类型

脚本侧的常用值统一为数据形状（命名键表或字符串），没有构造函数，也不带方法；接收点按同一形状解析，校验失败抛 Lua 错误。

| 值         | 形状                            | 说明                                                                 |
|------------|---------------------------------|----------------------------------------------------------------------|
| 坐标       | `{x = 数字, y = 数字, z = 数字}` | 三个字段必填。浮点坐标用于位置查询与传送                             |
| 方块坐标   | 同上                            | 接收点按向下取整落到方块网格，负数不会朝零截断                       |
| 朝向       | `{yaw = 数字, pitch = 数字}`    | 单位为度；`yaw` 为水平旋转，`pitch` 为俯仰                           |
| 命名空间键 | `"namespace:path"` 字符串       | 用于文本组件的 `font` / `storage` / `show_item.id` / `show_entity.type` |
| 文本组件   | 见「文本组件描述符」节          | 字符串 = 纯文本快捷路径                                              |

```lua
local p = player.position(uuid)                  -- {x = ..., y = ..., z = ...}
arena.teleport(uuid, p, {yaw = 0, pitch = 0})    -- 坐标 + 可选朝向
arena.clear_chest({x = 10, y = 64, z = -3})      -- 方块坐标按向下取整落格
```

## voidairrace（元数据）

| 成员                      | 类型 | 说明                                                       |
|---------------------------|------|------------------------------------------------------------|
| `voidairrace.api_version` | 数字 | 插件 API 版本号（当前 5）；包元文件 `api` 字段约束的就是它 |

## server

| 函数                         | 说明                                                                                                           |
|------------------------------|----------------------------------------------------------------------------------------------------------------|
| `server.broadcast(message)`  | 向全服广播一条文本消息；`message` 为字符串（= 纯文本组件快捷路径）或文本组件描述符表（见「文本组件描述符」节） |
| `server.online_players()`    | 返回当前全部在线玩家的 UUID 字符串数组（1 起始索引）                                                           |

## player

玩家以 UUID 字符串表示（值语义）；除 `online` 外，玩家不在线即抛错

| 函数                      | 说明                                                                                           |
|---------------------------|------------------------------------------------------------------------------------------------|
| `player.position(uuid)`   | 返回玩家所在世界坐标表 `{x=, y=, z=}`                                                          |
| `player.team_of(uuid)`    | 返回玩家所属队伍的数字 Id（1 起始，与内置队伍顺序一致）；未入队返回 `nil`                      |
| `player.online(uuid)`     | 返回布尔值：玩家是否在线；UUID 本身非法即抛错（与是否在线无关），离线玩家不抛错                 |
| `player.play_state(uuid)` | 返回玩家在 `play` 状态体系下的状态 Id 键名（`"free"` / `"playing"`）；状态未初始化返回 `nil`   |

## arena

| 函数             | 说明                                                                                                                   |
|------------------|------------------------------------------------------------------------------------------------------------------------|
| `arena.borrow()` | 借用一个空闲竞技场，返回竞技场句柄表；无空闲即抛错（错误消息列出各占用者）。借入者自动登记为本包，用于审计与包卸载清扫 |

### 竞技场句柄

`arena.borrow()` 返回的表。借用协议由脚本驱动：`load` → 使用（`teleport` / `clear_chest`）→ `release`；包卸载时未归还的竞技场由引擎统一归还（记日志）

| 函数                            | 说明                                                                                                              |
|---------------------------------|-------------------------------------------------------------------------------------------------------------------|
| `arena.load(path)`              | 将包内世界模板目录加载到竞技场；路径规则同 `resource.read_asset`（包根相对，`pkgid:path` 可跨包，须为已声明依赖） |
| `arena.release()`               | 归还竞技场：世界卸载且不保存修改，场内玩家传回出生点。归还后句柄失效（任何函数再调用即抛错）                      |
| `arena.teleport(uuid, pos[, rot])` | 把玩家传送到竞技场世界内的指定坐标；`pos` 为坐标表，`rot` 为可选朝向表，省略时保留当前朝向                  |
| `arena.clear_chest(pos)`           | 清空竞技场世界内指定方块的箱子（坐标按向下取整落格）；该坐标不是箱子时抛错                                  |

已登记为比赛区域（`match.widen`）的竞技场手动归还通道关闭（`release` 抛错），归还职责移交比赛结束流程；`teleport` / `clear_chest` 在比赛结束前仍可用

### 修改权限边界

用户包只能修改自己借到的竞技场，以及自己有修改权的比赛——自己注册地图的比赛，或本场已启用自己 Lua 规则的比赛。归属裁定在引擎侧统一进行，不暴露给脚本，越界即抛错：

- 竞技场资源：`arena.load` / `arena.clear_chest` 要求借用者是当前包；`match.widen` 只能登记本包借到的竞技场
- 玩家：`arena.teleport` 除借入者校验外，还要求目标玩家属于上述比赛（含已淘汰者）。地图开局回调 `on_start` 执行时比赛处于启动阶段，同样放行；规则被本场启用即授予其来源包同等修改权
- 没有进行中的比赛时，`arena.teleport` 一律抛错——即使竞技场是自己借的，也不能借此挪动无关玩家
- 事件回调只递值载荷（UUID、状态名等），不暴露可修改的实体对象；读取类 API 不受此限

## event

| 函数                       | 说明                                                                                                                                                                              |
|----------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `event.on(name, callback)` | 订阅引擎事件；`name` 为下方「事件」表里的名称（未知即抛错）。同一事件可登记多个监听器（含同一函数重复登记），按登记顺序调用；回调在主线程执行，事件字段作为位置参数传入，每次调用单独计算指令预算（单次最多执行的 tick 数）。无返回值 |
| `event.off(callback)`      | 按监听器函数退订：移除该函数在所有事件类型上的全部登记（函数须为登记时的同一个函数值）；未登记时静默无操作                                                                        |

### 事件列表

| 事件名                  | 回调签名                             | 触发时机                                        |
|-------------------------|--------------------------------------|-------------------------------------------------|
| `"player_join_match"`   | `function(uuid)`                     | 玩家加入比赛（开局不会为初始参赛者补发）        |
| `"player_leave_match"`  | `function(uuid)`                     | 玩家退出比赛（淘汰/离场）                       |
| `"match_start"`         | `function()`                         | 比赛开始                                        |
| `"match_state_changed"` | `function(state_name)`               | 比赛状态变化（不含开始与结束）                  |
| `"match_over"`          | `function()`                         | 比赛结束                                        |
| `"player_join"`         | `function(uuid)`                     | 玩家加入服务器                                  |
| `"player_quit"`         | `function(uuid)`                     | 玩家离开服务器                                  |
| `"player_death"`        | `function(uuid, killer_uuid_or_nil)` | 玩家死亡；击杀者是玩家时给出其 UUID，否则 `nil` |
| `"player_respawn"`      | `function(uuid)`                     | 玩家重生                                        |
| `"player_move"`         | `function(uuid, pos)`                | 玩家所在方块变化；同方块内走动与转头不触发      |

回调抛错时记日志并广播原因，不自动终止比赛。参数只含值（UUID 字符串、状态名、坐标表），不暴露事件对象或比赛对象，也不支持取消与改写

`player_move` 是唯一按位置触发的事件：只在跨方块时派发，同一玩家两次派发至少间隔 50ms（约每秒 20 次上限），坐标表为派发时玩家所在位置、不保证覆盖途经的每个方块；无人订阅时桥接在源头直接返回。需要更细的位置可在 `tick` 回调里经 `player.position` 轮询

## register

类别注册函数，描述符（表）为唯一参数。注册只发生在脚本执行期；任何校验失败导致整包加载失败。`id` 只写键名（小写字母/数字/下划线/连字符），插件自动加包前缀。全部字段：

| 函数                        | 必填字段                    | 可选字段                                  | 可选回调                                               |
|-----------------------------|-----------------------------|-------------------------------------------|--------------------------------------------------------|
| `register.map(descriptor)`  | `id`、`max_teams`（正整数） | `names`、`description`、`authors`、`tags` | `on_start(match)`、`on_over(match)`                    |
| `register.rule(descriptor)` | `id`                        | `names`、`description`、`authors`、`tags` | `on_enable(match)`、`on_disable(match)`、`tick(match)` |
| `register.tag(descriptor)`  | `id`                        | `names`、`description`、`authors`         | —                                                      |

- 展示字段 `names` / `description` / `authors` / `links` 为数组，每项为字符串（= 纯文本组件快捷路径）或文本组件描述符表；`display_version` / `version` 为单值（前者组件、后者正整数）
- `tags`：字符串数组；裸键自动加包前缀，跨命名空间写全名 `ns:key`；引用必须是已注册标签（自身包、插件内置或已声明依赖），规则描述符中的引用须 `register.tag` 先行
- 回调收到的 `match` 即比赛句柄；`on_over` / `on_disable` 失败只记日志不阻断结束流程，其余回调失败即比赛启动/规则启用失败

## 文本组件描述符

接收点（`server.broadcast`、`register.*` 展示字段）接受字符串（= 纯文本组件快捷路径）或描述符表——组件在 Lua 侧是数据形状，转换单向（描述符 → 组件）。描述符为 snake_case，样式字段内联在组件表上，对应 Minecraft 文本组件定义（Paper 1.21.11 / Adventure 4.26.1 支持范围）：

| 字段                                                              | 说明                                                                                                                                                          |
|-------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `type`                                                            | 组件类型：`"text"`（缺省）/ `"translatable"` / `"keybind"` / `"score"` / `"selector"` / `"nbt"`                                                               |
| `text`                                                            | text 类型的内容（可省，缺省空文本）                                                                                                                           |
| `translate` / `fallback` / `args`                                 | translatable：键必填；fallback 可选；args 为数组，每项可嵌套任意描述符                                                                                        |
| `keybind`                                                         | keybind 类型的按键绑定标识（如 `"key.jump"`），必填                                                                                                           |
| `objective` / `name`                                              | score：objective 必填；name 缺省空串（= 读者自身）                                                                                                           |
| `selector` / `separator`                                          | selector：选择器必填（如 `"@p"`）；separator 可选                                                                                                             |
| `block` / `entity` / `storage` / `nbt` / `interpret`              | nbt：来源三选一（block 坐标串支持 `~`；entity 为选择器或 UUID；storage 为资源路径）；`nbt` 为 NBT 路径必填；interpret 存在即为 true                           |
| `color`                                                           | 颜色名（`"red"` 等 16 色）或 `"#RRGGBB"`                                                                                                                      |
| `bold` / `italic` / `underlined` / `strikethrough` / `obfuscated` | 三态装饰：true 显式开 / false 显式关 / 省略继承                                                                                                               |
| `font`                                                            | 字体 Key 串                                                                                                                                                   |
| `insertion`                                                       | 按住 Shift 点击时插入聊天框的文本                                                                                                                             |
| `click_event`                                                     | 表：`action` + `value`。action 闭集：`open_url`（http/https）/ `open_file` / `run_command` / `suggest_command` / `change_page`（正整数）/ `copy_to_clipboard` |
| `hover_event`                                                     | 表：`action` + 内容。`show_text`（value=字符串/描述符）/ `show_item`（id 必填 + count）/ `show_entity`（type + id(UUID) 必填 + name）                         |
| `extra`                                                           | 子组件描述符数组，任意嵌套（深度上限 32）                                                                                                                     |

校验失败抛 Lua 错误，错误消息携带嵌套路径。

## resource

| 函数                          | 说明                                                                                         |
|-------------------------------|----------------------------------------------------------------------------------------------|
| `resource.read_asset(path)`   | 读取资产文件，返回二进制安全的字符串；大小受上限约束。路径规则同 `arena.load`                |
| `resource.list_assets(path?)` | 列出资产目录的直属条目，返回字符串数组，目录条目名以 `/` 结尾；`path` 省略或空串时列出本包根 |

## 比赛句柄 match

地图与规则回调收到的 `match` 参数——薄门面，每次回调现造，无需脚本管理生命周期。前缀「进行中」的函数要求比赛处于进行中；「查询」类函数在地图 `on_over` 收尾回调中也可用，其余场合比赛已结束即抛错

| 函数                        | 前置   | 说明                                                                                                                                                               |
|-----------------------------|--------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `match.state()`             | 无     | 返回比赛状态名字符串（如 `"IN_PROGRESS"`），与比赛状态枚举一一对应；唯一在任何阶段都可调用的函数                                                                    |
| `match.contestants()`       | 查询   | 返回初始参赛者的 UUID 字符串数组（1 起始索引）——比赛开始时在场的玩家                                                                                               |
| `match.survivors()`         | 查询   | 返回当前仍存活的参赛者 UUID 字符串数组                                                                                                                              |
| `match.eliminated()`        | 查询   | 返回已淘汰的参赛者 UUID 字符串数组                                                                                                                                  |
| `match.surviving_teams()`   | 查询   | 返回仍有存活参赛者的队伍数字 Id 数组（1 起始）                                                                                                                      |
| `match.player_ranking()`    | 查询   | 返回玩家排行 UUID 字符串数组（1 起始索引，第 1 项为第一名）：先退赛者在前，未退赛者按加入顺序排末尾                                                                  |
| `match.team_ranking()`      | 查询   | 返回队伍排行数字 Id 数组（1 起始索引，第 1 项为第一名）：按队伍首个成员退赛的先后，无法映射到内置队伍的条目被跳过                                                    |
| `match.join(uuid)`          | 进行中 | 使指定玩家加入本场比赛：已在本场幂等；已淘汰者、离线者、非空闲状态者拒绝并抛错                                                                                       |
| `match.leave(uuid)`         | 进行中 | 使指定玩家退出比赛（淘汰）；玩家不在参赛集合中时静默无操作                                                                                                          |
| `match.stop()`              | 进行中 | 结束本场比赛；仅当句柄属于协调器管理的当前比赛，否则抛错。收尾流程（组件卸载、`on_over`、`match_over` 事件）由引擎统一执行，调用后本句柄失效                          |
| `match.remaining()`         | 进行中 | 返回剩余比赛时长（tick 数，非负整数）                                                                                                                               |
| `match.set_remaining(n)`    | 进行中 | 设置剩余比赛时长；`n` 为 tick 数，须为非负整数                                                                                                                      |
| `match.time_flow()`         | 进行中 | 返回比赛时间是否随 tick 减少（布尔值）                                                                                                                              |
| `match.set_time_flow(flag)` | 进行中 | 设置比赛时间是否随 tick 减少：`true` 减少、`false` 暂停                                                                                                             |
| `match.widen(arena, tag)`   | 进行中 | 把竞技场登记为本场比赛的区域；`arena` 为竞技场句柄表，`tag` 为区域标签名（当前可用 `"main"`）。登记后竞技场归还职责移交比赛结束流程                                |
| `match.enable_rule(spec)`   | 进行中 | 在比赛中启用指定规则；`spec` 为规则 Id 字符串（裸键 = 自身包命名空间，或 `ns:key` 全名），命名空间须为自身包 / 插件内置 / 已声明依赖；规则须已注册，启用失败即抛错 |
